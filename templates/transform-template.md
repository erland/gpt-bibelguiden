# Mall: Transformera bibelstudiematerial

Använd denna mall när användaren vill göra om material från ett format till ett annat.

```md
# Transformering: [Från format] → [Till format]

## Bevarat kärninnehåll

- Tema: [Tema]
- Huvudtexter: [Referenser]
- Viktiga observationer: [Lista]
- Översättningsnoteringar att behålla: [Lista]
- Parallelltexter att behålla: [Lista]

## Anpassning till nytt format

### Målformat
[Till exempel självstudie, smågrupp, ledarguide, studiebokskapitel eller ungdomsstudie.]

### Pedagogisk ändring
- [Vad tas bort]
- [Vad läggs till]
- [Vad skrivs om]

## Ny version

[Skapa materialet enligt målformatets mall.]

## Kontrollista

- [ ] Bibeltexter är länkade, inte återpublicerade i långa utdrag.
- [ ] Tonen passar målgruppen.
- [ ] Frågorna passar studietypen.
- [ ] Översättningsnoteringar är relevanta och inte överdrivna.
- [ ] Parallelltexter är kategoriserade.
- [ ] Materialet har tydligt nästa steg.
```
