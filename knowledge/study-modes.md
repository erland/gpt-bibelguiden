# Studietyp och arbetslägen för Bibelguiden

Bibelguiden ska kunna skapa material i flera arbetslägen. Arbetsläget påverkar struktur, ton, frågor, tidsupplägg och hur fördjupning presenteras.

## 1. Smågrupp

Syfte: stödja ett gemensamt samtal runt bibeltexten.

Kännetecken:
- gemensam inledning
- bibellänkar för högläsning eller egen läsning
- öppna diskussionsfrågor
- följdfrågor
- ledaranteckningar
- tidsbudget
- praktisk tillämpning som gruppen kan prata om

Undvik:
- för långa textblock
- alltför akademiska utvikningar
- frågor som bara har ett rätt svar

## 2. Självstudie

Syfte: stödja personlig bibelläsning, reflektion och tillämpning.

Kännetecken:
- tydlig läsrytm
- kort förklarande introduktion
- bibellänkar i stället för långa citat
- personlig reflektion
- journalprompter
- självtest/kontrollfrågor
- bön eller avslutande reflektion
- minnesvers som referens och länk
- konkret tillämpning för dag/vecka
- valbar fördjupning

Undvik:
- gruppspråk som ”samtala i gruppen”
- att ersätta bibelläsning med sammanfattning
- för många parallelltexter i huvudflödet

## 3. Studiebok

Syfte: skapa ett större sammanhängande material som kan exporteras till PDF/EPUB eller användas kapitelvis.

Kännetecken:
- boktitel, undertitel och målgrupp
- tydlig progression
- återkommande kapitelstruktur
- bibellänkar
- fördjupningsrutor
- reflektions- eller diskussionsfrågor beroende på mål
- bilagor som ordlista, tidslinjer eller läsplan

## 4. Ledarguide

Syfte: hjälpa ledaren att förbereda och leda samtalet.

Kännetecken:
- mål med passet
- vad ledaren bör läsa i förväg
- vanliga missförstånd
- känsliga frågor
- följdfrågor
- förslag om samtalet fastnar
- förslag på hur tiden kan disponeras

## 5. Ungdomsstudie

Syfte: göra material begripligt, konkret och engagerande för yngre deltagare.

Kännetecken:
- kortare pass
- enklare språk
- konkreta vardagsexempel
- färre men bättre frågor
- praktiska övningar
- tydlig koppling till vardagsval, relationer och tro

## 6. Transformering

Syfte: göra om ett befintligt material till ett annat format utan att tappa kärninnehållet.

Exempel:
- smågrupp → självstudie
- självstudie → smågrupp
- predikan → smågruppsmaterial
- bokkapitel → 4 veckors studie
- studieutkast → ledarguide

Transformeringsregler:
- Bevara tema, huvudtexter och centrala observationer.
- Anpassa frågor, ton och tidsupplägg.
- Skriv om rubriker så att de passar nytt användningssätt.
- Ta bort delar som inte passar målformatet.
- Lägg till saknade delar enligt målformatets mall.
